============================================================================
IT Network Monitor - دليل تشغيل وتثبيت التطبيق على أي جهاز جديد
============================================================================

المتطلبات:
- نظام تشغيل Windows 10 أو Windows 11 أو Windows Server (64-bit).
- لا تحتاج لتثبيت Flutter أو Dart أو Visual Studio أو أي برامج إضافية.
- النسخة مستقلة بذاتها ومضمنة كافة المكتبات وملفات التشغيل لتعمل مباشرة دون أي إعداد برمجي.

----------------------------------------------------------------------------
طريقة التشغيل على أي جهاز جديد (خطوات بسيطة وسريعة):
----------------------------------------------------------------------------

1. فك ضغط الملف (Extract ZIP):
   - قم بنقل ملف ZIP إلى أي مسار على جهازك (مثلاً على سطح المكتب أو في C:\ITNetworkMonitor).
   - اضغط كليك يمين على الملف المضغوط واختر "Extract All..." (فك الضغط بالكامل).

2. التشغيل المباشر للواجهة الرسومية (Desktop GUI Dashboard):
   - افتح المجلد الناتج بعد فك الضغط.
   - اضغط مرتين (Double Click) على:
     it_network_monitor.exe
     أو على الملف:
     START_MONITOR.bat
   - سيفتح التطبيق مباشرة بواجهة المستخدم للبدء في مراقبة الأجهزة والشبكة وإدارتها.

3. التثبيت كخدمة دائمة في خلفية الويندوز (Always-On Windows Service - لأجهزة السيرفر):
   - إذا كنت تريد تشغيل نظام المراقبة كخدمة دائمة في خلفية الويندوز لا تتوقف عند إغلاق واجهة التطبيق أو تسجيل الخروج:
   - اضغط كليك يمين على ملف:
     install_windows_service_scm.bat
   - واختر "Run as Administrator" (تشغيل كمسؤول).
   - سيتم تثبيت الخدمة باسم ITNetworkMonitorService في خدمات الويندوز (services.msc) لتعمل تلقائياً عند إقلاع النظام وتستأنف عملها عند أي إعادة تشغيل.

4. إيقاف وإزالة الخدمة (في حال الرغبة):
   - اضغط كليك يمين على:
     uninstall_windows_service_scm.bat
   - واختر "Run as Administrator".

----------------------------------------------------------------------------
ملاحظات الأمان وحفظ البيانات:
- البرنامج مؤمن تماماً وفقاً لأفضل ممارسات الأمان المحلية (Least-Privilege ACLs).
- البيانات والإعدادات تُحفظ تلقائياً في المسار القياسي للنظام: %ProgramData%\ITNetworkMonitor.
